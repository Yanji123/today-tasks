# 今日任务 · Today Tasks

一个轻量的 Windows 桌面任务便签，使用 PowerShell 和 Windows Forms 实现。无需安装额外依赖，双击即可运行。

## 功能

- 添加、编辑任务文字，勾选完成；支持 Ctrl / Shift 多选删除及清除已完成。
- 可选截止日期（DDL），也可进一步指定小时和分钟。
- 四级重要程度：低、普通、重要、非常重要。
- 根据截止时间和重要程度呈现浅红到深红的背景，已完成任务淡化显示。
- 支持按 DDL、重要程度或底色深浅排序，并记住排序选择。
- 楷体字体、柔和配色、圆角按钮及可调透明度。
- 可切换置顶，支持拖动四边和四角调整窗口大小，并记住尺寸。
- 自动保存任务，关闭后重新打开仍然保留。
- 同一 Windows 会话内只运行一个实例。

## 运行环境

- Windows 10 / Windows 11。
- Windows PowerShell 5.1（系统自带），.NET Framework / Windows Forms。
- 启动入口使用 Windows Script Host；受组织策略限制的电脑可能禁用此组件。
- 楷体使用系统字体 `KaiTi`；缺少该字体时由 Windows 选择替代字体。本项目不分发字体。

## 快速开始

1. 下载仓库 ZIP 并完整解压到可写文件夹，或使用 Git 克隆。
2. 双击 `Start.cmd` 或 `启动便签.vbs`。
3. 在底部输入任务，点击“添加”或按回车，在弹出的窗口里设置可选 DDL 和重要程度后保存。

启动器隐藏 PowerShell 控制台，因此不会留下需要手动关闭的命令窗口。请使用便签自身的关闭按钮退出。

若系统禁用了 VBS，可打开 Windows PowerShell，进入项目目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File ".\今日任务.ps1"
```

该命令仅对本次进程设置执行策略，不修改系统全局策略。使用此排错方式时，关闭 PowerShell 窗口也会结束便签。

## 使用方法

| 操作 | 方法 |
| --- | --- |
| 修改文字、DDL、重要程度 | 双击任务，或选择一条任务后点击“编辑任务” |
| 完成任务 | 点击任务左侧复选框 |
| 批量删除 | 按住 Ctrl 或 Shift 选择多条，再点击“删除选中” |
| 清除已完成 | 点击“清除已完成” |
| 调整透明度 | 拖动底部滑块，数值越大越透明 |
| 保持窗口在其他软件上方 | 勾选“置顶” |
| 调整窗口大小 | 拖动窗口边框或四角 |
| 排序 | 使用列表上方的下拉框 |

DDL 的时间不是必填项。只设置日期时，以该日结束作为截止时间；勾选“指定时间”后精确到分钟。时间按照运行电脑的本地时间解释，不包含时区或跨设备同步。

任务的红色深浅由重要程度和未来 14 天内的紧迫程度共同计算；已到期或逾期时紧迫程度达到最高。颜色每分钟更新一次。此版本没有系统通知或到期弹窗。

## 数据保存与备份

所有数据保存在程序所在文件夹，使用过程中无需手动保存：

| 文件 | 内容 |
| --- | --- |
| `tasks.json` | 任务文字、完成状态、DDL、重要程度 |
| `tasks.json.bak` | 上一次保存前的任务数据备份 |
| `appearance.json` | 透明度设置 |
| `sorting.json` | 排序选择 |
| `window.json` | 窗口尺寸 |
| `startup.log` | 启动诊断日志 |

添加、编辑、完成和删除任务都会保存。保存先写临时文件，再替换任务文件，并保留上一份数据备份。备份并非完整历史记录。

**升级时保留上述数据文件，只替换程序文件。请勿直接删除整个程序目录。** 建议定期把 `tasks.json` 复制到其他位置备份。数据以明文保存，适合个人本地使用。

恢复备份：先退出便签，将当前 `tasks.json` 另存一份，再把 `tasks.json.bak` 复制为 `tasks.json` 后重新启动。

个人任务、设置和日志已列入 `.gitignore`，不应上传到仓库。

## 项目结构

```text
今日任务.ps1    # 主界面、任务存储、DDL 和排序逻辑
Start.cmd       # 双击启动入口

note.ico        # 专用便签图标
.gitignore      # 排除个人数据和日志

```

## 已知限制

- 当前是普通 Windows 桌面窗口；未置顶时遵循系统窗口层级，并非嵌入桌面图标层的组件。
- 透明度作用于整个窗口，包括文字和控件；过高的透明度会影响可读性。
- 任务栏可能仍按 PowerShell 进程分组；此项目尚未打包成独立 EXE。
- 截止时间没有提醒通知、云同步和重复任务功能。

## 排错

启动无窗口时，先查看 `startup.log`，或使用上述 PowerShell 命令运行以显示错误。若便签已运行，重复启动不会再创建第二个窗口，可通过 Alt + Tab 查找现有窗口。

主脚本使用 UTF-8 BOM 编码以兼容 Windows PowerShell 5.1，编辑时请保留编码。
